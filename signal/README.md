# ALFA Signal — автономный «ловец сигнала»

Отдельное маленькое приложение (пакет `com.checkout.alfasignal`), замена
MacroDroid. Ставится **рядом** с ALFA SMS, не конфликтует с ним.

## Что делает
Слушает **все входящие SMS**. Как только в тексте (от любого номера)
встречается слово-триггер — **«символ»** — шлёт **GET**-запрос на вебхук:

```
https://project.alfa-vpn.ru/api/signal/Karenchikosikus123
```

Сервер по этому вебхуку запускает работу у всех, кто включил «Отработать по
сигналу» (и если сейчас не идёт расписание).

## Как пользоваться
1. Установить APK.
2. Открыть приложение → **«Выдать доступ к SMS»** (разрешить).
3. Проверить, что ссылка вебхука и слово-триггер верные (по умолчанию уже
   вписаны). При желании — поменять и **«Сохранить»**.
4. Кнопка **«Тест»** — сразу дёрнуть вебхук и увидеть ответ (HTTP-код).
5. Тумблер **«Слежение включено»** держать включённым.

Работает в фоне: SMS ловится, даже когда экран приложения закрыт. Каждое
срабатывание пишется в **Журнал** и показывается уведомлением. Слово-триггер и
адрес вебхука можно менять прямо в приложении.

## Отправка SMS по интервалу
Во втором блоке — периодическая отправка:
- **Текст сообщения** (по умолчанию `9762000179660278 13999`);
- **Номер получателя** (по умолчанию `7878`);
- **Интервал в секундах** — быстрые кнопки **30 сек / 60 сек** или своё число;
- **▶ Запустить отправку / ■ Остановить**.

Отправка идёт фоновым сервисом (уведомление «отправка идёт», wake-lock), поэтому
продолжается с закрытым экраном. Нужен доступ к отправке SMS (кнопка «Выдать
доступ к SMS»). Каждая отправка попадает в журнал. Действуют тарифы оператора.

## Работа в фоне (обязательно!)
Прошивки (Xiaomi/MIUI, Samsung, Huawei, Oppo и др.) убивают фоновые приложения и
«замораживают» их ради экономии батареи — тогда и отправка встаёт, и приём
«символ» может не сработать. Чтобы этого не было:
1. В приложении → блок «Доступ» → **«Отключить экономию батареи»** (соглашаемся).
2. В настройках телефона для «ALFA Signal» включить **автозапуск** и снять любые
   ограничения фоновой активности (у каждого бренда называется по-своему).
3. В списке недавних приложений «залочить» карточку ALFA Signal, чтобы её не
   смахивало.

Приём «символ» работает через системный приёмник SMS (приложение будится само на
входящую), поэтому в фоне он надёжнее отправки — но тем же ограничениям батареи
он тоже подчиняется. После перезагрузки телефона отправка сама возобновляется,
если была включена.

## Сборка
```
./gradlew :signal:assembleRelease
# APK: signal/build/outputs/apk/release/signal-release.apk
```
Свой вебхук/слово можно вшить при сборке: `-PsignalUrl=...`.
