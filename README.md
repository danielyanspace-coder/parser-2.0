# ALFA SMS — централизованная система

Версия 2.0. Всё управление централизовано: **приложение на Android — только
сканер QR-кода**, а все настройки задаются в **мини-аппе Telegram** отдельно для
каждого устройства. Отправка идёт на фиксированный номер **7878**.

Старый проект (`danielyanspace-coder/parser`) не затрагивается. Рабочий домен —
поддомен `project.alfa-vpn.ru` (основной сайт и VPN не трогаются).

📖 **Установка по шагам — в [DEPLOY.md](DEPLOY.md).**

## Компоненты

| Компонент | Каталог | Что делает |
|-----------|---------|------------|
| **Сервер** | [`server/`](server/) | Node.js без зависимостей. Мини-апп + API, админ-API (только для одного Telegram ID), API устройств с мгновенной доставкой команд (long-poll). Хранилище — JSON. |
| **Мини-апп** | [`server/public/miniapp.html`](server/public/miniapp.html) | Светлая тема, экраны: главная, «Настройка интервалов», устройство, редактор платежа, админ-панель. Креативный логотип, футер «Production by Splinter & Sergio», кнопка тех-поддержки. |
| **Android APK** | [`app/`](app/) | Только сканер QR + фоновый сервис. Тянет с сервера расписание и платежи, шлёт SMS на 7878 и отрабатывает цикл «символ»→«Ок»→«успешно». |

## Модель

**Общее на токен (в «Настройке интервалов», применяется ко всем устройствам):**
- интервал отправки (+ быстрые 5/10/15);
- промежутки/расписание (окна времени суток);
- «Повторять каждый день по этому сценарию»;
- время старта (если промежутки не заданы).

**На каждое устройство:**
- ползунок «Активно/неактивно» (зелёный/белый);
- список **платежей** (блоков), идущих по очереди. Каждый платёж:
  - **Реквизиты** (бывш. «Сообщение 1»);
  - **Сумма** (бывш. «Сообщение 2»);
  - ползунок **«несколько платежей на этот реквизит с той же суммой»** →
    поле **«Количество платежей»** (сколько циклов подряд с этим блоком).

**Как исполняется на телефоне:** SMS = «Реквизиты + Сумма» → на номер **7878**
по интервалу; на входящее «символ» отвечает «Ок»; после «успешно» — если блок
набрал своё количество платежей, переходит к следующему блоку, иначе повторяет
текущий; после последнего блока — стоп.

## Сотрудники (совместный доступ)
Первый, кто вошёл по токену, становится **владельцем**. В мини‑аппе у него есть
раздел **«👥 Сотрудники»**: кнопка «Добавить сотрудника» выдаёт одноразовый
код‑приглашение (действует 7 дней). Сотрудник вводит этот код вместо токена и
получает **полный доступ** к устройствам и настройкам — но **не может** добавлять
других сотрудников. Владелец видит список сотрудников и может их убрать.

## Управление работой
- **Тумблер «Начать немедленную работу со всех устройств»** — мгновенный запуск
  всех активных устройств (эквивалент старого «Сейчас → Поставить в работу»).
  Без задержки: устройства держат long-poll, сервер будит их в момент нажатия.
- **Ползунок «Активно/неактивно»** на устройстве — неактивные не участвуют в
  общем запуске, и запланированные отправки у них не срабатывают.
- **Расписание запускается само** и имеет приоритет: сервер включает работу в
  начале окна (часовой пояс — по `TZ` сервера).
- **Ползунок «Отработать по сигналу»** (бета) — при внешнем сигнале («символ» с
  8464, ловится MacroDroid → вебхук) активные устройства пользователя стартуют
  **только если сейчас не идёт расписание**. Сигнал шлёт первый платёж 3 раза по
  1 c; нет «символ» — стоп, есть — «Ок» и дальше по остальным реквизитам.
- **«Ок» на «символ» отправляется всегда** — включена система или нет.
- **Остановка + отчёт:** когда каждое активное устройство завершилось (с 7878
  пришло «Оплата не произведена» или отработаны все платежи).
- **🌙 Переключатель темы** (светлая/тёмная) — вверху справа на главной.

Номера: платежи → **7878** (оттуда «Операция отклонена»/«Оплата не произведена»);
«символ»/«успешно» → с **8464** (туда же «Ок»).

## Отчёты в боте
После завершения работы (все устройства отработали или общий тумблер выключен)
бот присылает пользователю отчёт: по каждому устройству — сколько отправлено,
какая была задача (сумма всех платежей) и сколько не отработано, с кнопкой
**«Доработать»**. Нажатие → подтверждение → система удаляет исполненные платежи
со всех устройств, оставляя только неисполненные, и просит выставить расписание.

Если платёжный шлюз (7878) присылает «Операция отклонена…», бот сразу
предупреждает владельца: какой реквизит отклонён и на каком устройстве.

## Обновления (OTA)
Приложение само проверяет наличие новой версии на сервере и предлагает
установить её поверх (без удаления). Админ публикует обновление загрузкой APK +
номера версии (см. [DEPLOY.md](DEPLOY.md)).

## Админка (только Telegram ID 8211351879)
Открывается прямо в мини-аппе у администратора («⚙ Админ-панель»):
- создание токенов со **сроком действия** и **лимитом устройств**;
- изменение лимита (выдать больше / забрать), продление срока;
- включить/выключить (мгновенный отзыв), отвязать Telegram, удалить;
- по каждому токену — **его расписание и платежи всех устройств**;
- **💸 сводка всех ушедших платежей** (по которым пришло «успешно») — общая сумма,
  разбивка по пользователям и последние операции;
- сводка: сколько устройств привязано/активно, к какому Telegram привязан токен.

Резервный вход по паролю — `project.alfa-vpn.ru/admin`.

## Нагрузка
6–7 пользователей × 15+ устройств ≈ 100 устройств — для HELs-2 (2 ядра / 4 GB)
запас 10–20×. Подробности в [DEPLOY.md](DEPLOY.md).

## Ответственное использование
Отправляйте сообщения только туда, куда у вас есть право отправлять. Действуют
тарифы оператора на SMS.
