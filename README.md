# ALFA SMS — централизованная система

Полностью переписанная (v2.0) версия системы рассылки SMS. Теперь всё
управление централизовано: **приложение на Android больше не содержит никаких
настроек — только сканер QR‑кода**, а все параметры задаются в **мини‑аппе
Telegram** отдельно для каждого устройства.

Старый проект (`danielyanspace-coder/parser`) не затрагивается — это отдельная
новая кодовая база. Рабочий домен — **alfa‑vpn.ru** (sensadog.ru не используется).

## Из чего состоит система

| Компонент | Каталог | Что делает |
|-----------|---------|------------|
| **Сервер управления** | [`server/`](server/) | Node.js без зависимостей. Админка токенов, API мини‑аппа, API устройств (привязка + мгновенная доставка команд). Хранилище — JSON‑файл. |
| **Мини‑апп Telegram** | [`server/public/miniapp.html`](server/public/miniapp.html) | Светлый интерфейс: вход по токену, общий переключатель «включить все устройства в работу», список устройств с ползунками активно/неактивно, все настройки на каждое устройство, добавление устройства через QR. |
| **Android‑приложение (APK)** | [`app/`](app/) | Только сканер QR + фоновый сервис. После привязки тянет свою конфигурацию с сервера и исполняет рассылку (интервалы, промежутки, лимит, цикл «символ»→«Ок»→«успешно»). |

## Как это работает

```
Админ ──создаёт токен (срок + лимит устройств)──► Сервер
                                                    │
Пользователь ──открывает мини‑апп в Telegram──────►─┤ вход по токену
   │                                                │ (Telegram ID привязывается к токену —
   │                                                │  повторно вводить не нужно)
   │ «Добавить устройство» → имя → QR ─────────────►│ создаётся слот + одноразовый код
   │                                                │
   ▼                                                │
 Телефон с APK ──сканирует QR──────────────────────►│ /api/device/pair  → deviceId + secret
   │                                                │
   │ ◄──── long‑poll /api/device/sync ─────────────►│ мгновенная доставка состояния
   │                                                │
Пользователь задаёт настройки на устройство ───────►│ сохраняются на сервере
Пользователь жмёт «Включить все устройства» ───────►│ globalOn=true
                                                    │
                          long‑poll возвращается ◄──┘ телефон СРАЗУ начинает рассылку
```

### Мгновенный запуск

Переключатель «Включить все устройства в работу» действует **без задержки** —
это эквивалент старого «Сейчас → Поставить в работу». Телефоны держат открытым
long‑poll‑запрос к серверу; в момент переключения сервер отвечает всем
устройствам сразу, и первая SMS уходит немедленно (в тестах — миллисекунды, а не
период опроса).

### Ползунки

- **Общий (сверху)** — запускает/останавливает рассылку на всех устройствах.
- **На каждом устройстве** — активно (зелёный) / неактивно (белый). Неактивные
  устройства не подчиняются общему включению, и запланированные отправки у них
  тоже не срабатывают.

## Настройки, которые задаются на каждое устройство

Все прежние поля приложения переехали в мини‑апп:

- номер телефона;
- сообщение — часть 1 и часть 2 (склеиваются через пробел);
- интервал отправки (секунды) + быстрые кнопки 5/10/15;
- промежутки отправки (окна времени суток, можно несколько) + «повторять каждый день»;
- время старта (если промежутки не заданы; пусто = сразу при включении);
- кол‑во отправок (лимит триггеров «символ»).

## Админка

`/admin` (Basic‑auth, пароль в `ADMIN_PASSWORD`):

- создать токен с **сроком действия** и **лимитом устройств**;
- изменить лимит устройств (выдать больше или забрать);
- продлить/сделать бессрочным срок действия;
- включить/выключить (мгновенный отзыв) и удалить токен;
- отвязать Telegram‑аккаунт от токена.

Если лимит устройств исчерпан, кнопка «Добавить устройство» в мини‑аппе
блокируется.

## Развёртывание — кратко

1. Поднять сервер (см. [`server/README.md`](server/README.md)) на `https://alfa-vpn.ru`.
2. В BotFather создать бота, выдать ему Web App с URL `https://alfa-vpn.ru/`,
   задать серверу `TELEGRAM_BOT_TOKEN`.
3. Собрать APK (`./gradlew assembleRelease`) и раздать пользователям.
4. В админке создавать токены и выдавать их пользователям.

## Ответственное использование

Отправляйте сообщения только на номера, которыми вы владеете, или на отправку
которым у вас есть явное разрешение. Массовая рассылка без согласия получателя
может являться незаконной. Действуют тарифы оператора на SMS.
